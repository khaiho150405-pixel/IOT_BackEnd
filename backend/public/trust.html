Kết nối an toàn tới AIoT Smart Room

Máy chủ trong nhà dùng chứng chỉ do chính nó cấp. Cài chứng chỉ gốc (CA) một lần trên mỗi điện thoại/máy tính để mở dashboard bằng HTTPS không bị cảnh báo và cài được thành ứng dụng.

1. Tải chứng chỉ gốc

Tải aiot-smart-room-ca.crt

Chỉ cài chứng chỉ này nếu bạn tin máy chủ AIoT trong nhà mình. Nó chỉ dùng để xác thực máy chủ AIoT, không cho phép xem dữ liệu của bạn.

2. Cài đặt

Android:

  1. Mở file vừa tải, hoặc vào Cài đặt → Bảo mật → Mã hóa và thông tin xác thực → Cài đặt chứng chỉ → Chứng chỉ CA.
  2. Chọn aiot-smart-room-ca.crt, xác nhận cài đặt.

iPhone / iPad:

  1. Mở liên kết tải bằng Safari, chọn Cho phép để tải hồ sơ.
  2. Cài đặt → Đã tải về hồ sơ → Cài đặt.
  3. Cài đặt → Cài đặt chung → Giới thiệu → Cài đặt tin cậy chứng nhận → bật AIoT Smart Room Local CA.

Windows: mở file → Install Certificate → Current User → Place all certificates in the following store → Trusted Root Certification Authorities.

3. Mở dashboard bằng HTTPS

Đang tải địa chỉ…

Sau khi mở, trên Android chọn ⋮ → Cài đặt ứng dụng (Chrome); trên iPhone chọn Chia sẻ → Thêm vào MH chính (Safari).
